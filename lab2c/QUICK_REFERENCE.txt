HARDWARE SETUP (12h Mode Button):
────────────────────────────────────────────────────────────────────

  GPIO2 → Button → GND
          with pull-up resistor (internal or external)

  Button press: Toggles between 12h display and 24h display
  (Only active when SELECT_12HOURS == 1)

KEY FUNCTIONS:
────────────────────────────────────────────────────────────────────

  clock_time_inc_second()        - Increment by 1 second
  clock_time_set_utc()           - Set specific time
  clock_time_get_utc()           - Get current UTC time
  clock_time_get_local()         - Get local time (with timezone)
  clock_time_format_string()     - Format for display
  clock_time_is_pm()             - Check AM/PM (12h mode only)
  clock_time_run_tests()         - Run test suite

INTERNAL TIME REPRESENTATION:
────────────────────────────────────────────────────────────────────

  Always stored in 24-hour format (0-23 hours)
  Conversion to 12h happens only at display time
  Formula: display_hour = hour % 12; if (hour % 12 == 0) hour = 12;

MEMORY USAGE (Assembler):
────────────────────────────────────────────────────────────────────

  24h Mode:  hours (1 byte), minutes (1 byte), seconds (1 byte) = 3 bytes
  12h Mode:  + am_pm (1 byte) = 4 bytes total

CASCADE OVERFLOW LOGIC:
────────────────────────────────────────────────────────────────────

  seconds: 0-59  →  rolls over to 0, increments minutes
  minutes: 0-59  →  rolls over to 0, increments hours
  hours:   0-23  →  rolls over to 0 (day boundary)

EXAMPLE USAGE:
────────────────────────────────────────────────────────────────────

  // Set to 11:59:59 AM (internal: 11:59:59)
  clock_time_set_utc(11, 59, 59);

  // Increment by 1 second
  clock_time_inc_second(time_us_64());

  // Result: 12:00:00 (displays as 12:00:00 PM in 12h mode)

  // Get current time
  int h, m, s;
  clock_time_get_utc(&h, &m, &s);
  // h=12, m=0, s=0

  // Format for display
  char buf[32];
  clock_time_format_string(buf, h, m, s, true);  // 12h format
  // Result: "12:00:00 PM"
