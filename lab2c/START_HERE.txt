                          KEY IMPLEMENTATION FACTS
═══════════════════════════════════════════════════════════════════════════════

INTERNAL TIME STORAGE:
  • Always in 24-hour format (0-23 hours)
  • No separate AM/PM storage
  • Conversion happens only at display time
  • Result: Minimal memory overhead

MODE SELECTION:
  • Compile-time: SELECT_12HOURS symbol
  • Runtime: Optional GPIO button (GPIO2)
  • Default: Configurable
  • Can be toggled without rebuild (optional feature)

OVERFLOW BEHAVIOR:
  • Cascading: Seconds → Minutes → Hours
  • Day wrap: 23:59:59 → 00:00:00
  • Special handling: 0 becomes 12, 12 stays 12
  • All transitions properly tested

CODE SIZE IMPACT:
  • 24h mode: ~2-3% smaller than 12h
  • 12h mode: Normal size with all features
  • Test code: Optional (not required for production)
  • Conditional: Only unused code is excluded
